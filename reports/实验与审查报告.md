# 知迹：全量实验与审查报告

本次完成开发规格的 MVP：数据质量、学生级划分、基线和 XGBoost、三组消融、正式 rENA、API 与教师端页面。LSTM 保留为第二阶段。本报告不声称模型已可用于真实学校自动决策。

## 数据与方案

- 原始文件 6,123,270 行，清洗后 6,032,040 条交互；排除 91,230 条记录。
- 学生 46,325 名，固定 70/15/15 划分为 32,427 / 6,949 / 6,949 名；具备预测所需长度的学生为 41,802 名。
- 预测样本 5,806,803 条；相邻时间相同的 1,747 个目标被排除。
- 模型使用最多 20 条历史；行为、情感、结果均来自锚点及以前。对未知和已知下一题上下文分别训练与评价。
- 所有模型选择与风险阈值来自验证集。测试集结果冻结，bootstrap 以学生为单位重复 1,000 次。PR-AUC 使用答错为正类的 average precision。

## ENA

- 14,539 个学生单位：稳定组 7,101，困难组 7,438；前 70% 构建网络，后 30% 定义表现组。
- 分组阈值仅取训练学生结果期错误率四分位：稳定组 ≤ 0.190476，困难组 ≥ 0.454545。
- rENA 0.3.1、EndPoint、binary co-occurrence，主窗口当前及前 4 行；同一分析的两组使用相同节点坐标与边宽比例。
- 主分析“答错—提示”困难减稳定约 +0.1002，学生级 95% CI [0.0968, 0.1036]。
- “重复尝试—慢反应”约 +0.0239；“挫败—困惑”约 −0.0106，与原先可能更强的假设方向相反。
- 三条预先关注的连接在窗口 2/4/6 和情感阈值 0.33/0.50/0.67 的单因素敏感性设置下方向一致。没有把五种设置说成完整 3×3 因子实验。
- 学生单位整体网络置换检验每次 1,000 次，当前五种设置 p≈0.001。边区间是未做多重比较校正的探索性区间，不能据此声称每条边独立显著。
- 网络是群体共现，不是情感测量、因果证据或个体风险解释。

## 严格审查与修复

- 修正文档 Python 3.11 与 XGBoost 3.4 的版本冲突；锁定 Python 和 R 依赖。
- 低基数类别改为 one-hot，知识点频次编码仅在训练数据拟合，随后重跑所有正式基线和 XGBoost 消融。
- 服务缺失知识点表示与训练不一致的问题已修复；两个上下文各 100 个真实锚点在线/离线概率差异为 0。
- 全量规范表两次清洗 SHA-256 相同，三份模型特征表重新生成后的 SHA-256 也逐一相同；缺失技能表示规范化迁移保留其他列和所有冻结特征键。
- Ruff、格式检查、mypy 通过；20 项 pytest 通过，包括合成 CSV→Parquet→split→features→XGBoost→rENA→API 集成测试。
- 四个页面从同一 Home 入口切换测试通过；本地浏览器实际查看了概览、学生详情和 ENA 网络。
- 真实产物主要 API 路由均返回 200；历史不足、倒序、情感越界、负次数、重复事件、未知学生、版本冲突和产物缺失均有测试。
- 测试依赖产生两条上游弃用警告，没有测试失败。历史探索脚本保留但不属于正式运行入口。
